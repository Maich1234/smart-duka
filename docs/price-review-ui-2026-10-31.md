# Price-review UI, 31 October 2026

The original dashboard card used unstyled native Text, omitted the app's Inter font family, missed dashboard gutters and expanded the full financial summary into the dashboard. The replacement uses explicit Inter typography throughout, a white surface, a restrained amber icon, a compact title, one potential-stock-shortfall amount when relevant and a 44-point review action. Dashboard and inventory placements now use their existing horizontal gutters; Insights retains its own padding. Healthy checks stay quiet, but a failed refresh still appears even when the last cached check was healthy.

The review screen groups the four figures in a wrapping two-column grid, uses adjacent selling/purchase price comparisons, and moves definitions and exclusions into an accessible disclosure. Product editing, variants, historical sales shortfalls, history pagination, editor attribution and QR PDF export remain available. Unknown costs and malformed stock remain explicit. Price history includes unit changes. Export has progress, error and completion feedback without claiming the user saved the file.

Independent verification: mobile TypeScript and web production build passed. Actual native components rendered through React Native Web and actual web React components rendered in headless Chromium with synthetic query/auth/service/navigation/native-chrome adapters. Inspected card/detail screenshots. Checked 320/390/768/1280 widths without horizontal overflow, long names, unknown costs, invalid stock, owner/staff rendering, summary navigation, figures, explanation disclosure, history opening/closing and units, report pagination, PDF failure and completion, refresh retries and loading/error/empty/stale data states. Native card text resolved to Inter; card height was under 280 pixels at 390-pixel width. No existing suite, production data edits or provider calls were used.

These checks do not verify native Android font scaling, the physical share sheet, device navigation or the live database. A fresh Android EAS preview requires a signed-in Expo session. No production merge or web deployment was performed by this change.
